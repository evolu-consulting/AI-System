1. Chuẩn bị

Chạy trong thư mục D:\AI\ai-system. Trong Claude Code gõ ! trước lệnh.

docker compose up -d --wait
bun run db:migrate
bun run db:seed
bun run dev

Cần có trong .env.local: SECRET_MASTER_KEY (tạo bằng bun run keys:dev nếu thiếu), SEED_ADMIN_PASSWORD, SMTP_URL=smtp://127.0.0.1:1025.

B. Tenant & User M1

C. Catalog: Secret, Workflow, Command, Feature M2

D. Group & Phân quyền M3

E. Quota, cảnh báo, Chi phí, Tổng quan M4

F. Nhật ký & Khôi phục M4

G. Import / Export M4 · platform

H. Xác thực hai bước (2FA) M4

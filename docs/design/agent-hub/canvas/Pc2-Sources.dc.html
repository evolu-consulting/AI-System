1 · Form git_remote (sửa)
Sửa nguồn · repo-app
Dùng để đọc repo riêng tư và đẩy nhánh / mở PR. Token không hiện lại sau khi lưu.
2 · Host chưa hỗ trợ (trên) · local_path (dưới)
Chỉ GitHub (github.com) hỗ trợ mở PR. Máy chủ git khác chỉ đẩy nhánh.
Chỉ nhánh (cố định)
Nguồn đường dẫn cục bộ không đẩy lên đâu cả. Người duyệt tải file .diff và tự git apply.

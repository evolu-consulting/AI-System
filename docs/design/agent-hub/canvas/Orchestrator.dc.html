Orchestrator

Agent nhận mọi tin nhắn, chọn agent chuyên trách (delegate), tự trả lời (answer) hoặc hỏi lại (ask). Tin bắt đầu bằng @agent đi thẳng tới agent đó.

Cấu hình mặc định

ChậmAgent này chạy CLI: mỗi quyết định khởi động CLI vài giây và chiếm slot subscription. Khi có API key, nên chuyển sang runtime llm với model rẻ.
Không có agent nào phù hợp
Lưu thay đổi ở đây sẽ chạy bộ câu kiểm thử định tuyến (mỗi câu 3 lần, lấy đa số). Tụt quá 1 câu so với baseline thì không lưu, trừ khi lưu đè có lý do.

# Test plan · P-d · e2e tối thiểu (phụ lục của [test-plan.md](test-plan.md))

Playwright, config `e2e/P-d/playwright.pd.config.ts` (đặt dưới `e2e/**/playwright*.config.ts` để `bun run test:all` tự nhận — CLAUDE.md Luật 4b), stack + seed như `e2e/P-c2` (`_pc2-support.ts`: hub-api + admin-api + web thật, runtime giả, `seedRun`). Chọn phần tử bằng **role + tên** theo [`plan-frontend.md`](plan-frontend.md) §7 (P-d1) và [`plan-frontend-d2.md`](plan-frontend-d2.md) §13 (P-d2); **câu chữ nguyên văn lấy từ [`plan-frontend-i18n.md`](plan-frontend-i18n.md) (i18n thắng khi lệch)**; bố cục tham khảo `mockup/01…04`. Tên `region "Giai đoạn n: <tên>"` là panel (`complementary "Chi tiết giai đoạn"`). Sau lưu: chờ `page.waitForResponse` (bẫy CONVENTIONS §2). Trạng thái chờ hẹn/thử lại dựng bằng SQL seed (stage `waiting_timer` + hàng `process_timers`), không chờ thời gian thật. Test chỉ kiểm tra những gì người dùng thấy; các lỗi cấu hình chỉ do API bắt (vd `ESCALATE_INVALID`) kiểm ở int, không ở e2e.

## Điều tra delta agent (F1, backend-lead, 2026-10-05)

**Kết luận:** lỗi phía Runtime (cấu hình env), không phải vòng đọc. Env job host (`sandbox/env.py` `CLI_QUIET_ENV`: `DISABLE_TELEMETRY`, `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`) làm CLI 2.1.286 **tắt GrowthBook** ⇒ cờ `tengu_fgts` trả mặc định `false` ⇒ tool (kể cả `StructuredOutput`) không gắn `eager_input_streaming` ⇒ API đệm giá trị chuỗi của input tool (`text`) tới khi xong rồi CLI phát cả loạt `input_json_delta` một lúc. Orchestrator (khối `text`) không phụ thuộc cờ này nên vẫn stream. Spike PY-S2 #2 stream được vì chạy `env -i` **không** có `CLI_QUIET_ENV` (GrowthBook bật, `~/.claude.json` `cachedGrowthBookFeatures.tengu_fgts = true`).

**Bằng chứng tĩnh (binary `_bundled/claude` 2.1.286):** `tpt(provider)`: `r = env CLAUDE_CODE_ENABLE_FINE_GRAINED_TOOL_STREAMING` (triBool); bật khi `r !== false && (firstParty && <base URL first-party> && R("tengu_fgts", false) || … || r === true)` ⇒ tool schema `eager_input_streaming = true`. `R()` = GrowthBook `getFeatureValueWithSource`; `isGrowthBookEnabled = !DISABLE_GROWTHBOOK && !ah()`, `ah()` gồm `ND()` = `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` hoặc `DISABLE_TELEMETRY` (hoặc `DO_NOT_TRACK`) có đặt ⇒ GrowthBook tắt ⇒ giá trị mặc định.

**Giả thuyết đã loại:** (a) scanner tắt vì thứ tự khoá — không: smoke có ~130 `job.delta` (scanner đã stream), spike lại thấy `status` → `text`; (b) pipe con→cha đệm — không: `child._emit` `flush()` mỗi sự kiện, Orchestrator cùng đường đi stream đều; spike mức SDK (không qua job host/pipe) tái hiện y hệt; (c) chọn sai khối — không: cả smoke lẫn spike chỉ có 1 khối `tool_use StructuredOutput` (index 0); (d) "có tool khác ⇒ CLI giữ input" — không phải do tool khác mà do env: cùng `Read`/`Grep` chỉ đổi biến env là hết dồn cục.

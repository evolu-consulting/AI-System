# H1 · Kết quả spike PY-02 — Claude Agent SDK thật trong WSL2 (2026-10-04)

Phụ lục của `plan-runtime.md` §13. Script: `apps/agent-runtime/spikes/sdk_spike.py` (+ `README.md`). FR: WRK-FR-10/11/14/15, WRK-BR-07.

**Môi trường:** Ubuntu 26.04.1 (WSL2, systemd), user `worker`, Python 3.14 venv `~/.venvs/agent-runtime`, `claude-agent-sdk==0.2.163` (CLI **đóng gói 2.1.286**; CLI cài riêng `~/.local/bin/claude` 2.1.289 không dùng), model mặc định `claude-opus-5-5`. Mọi ca chạy dưới `env -i HOME=/home/worker PATH=/usr/local/bin:/usr/bin:/bin LANG=C.UTF-8 setsid -w` (giống job host). Output JSON: `/tmp/spike/out/<ca>.json` (không lưu repo — có session id).

**Lượt gọi model: 9** (`client-tools` ×3 — 2 lần model từ chối, `query-hook`, `no-tools`, `control-claude-md`, `structured`, `resume`, `at-file`; ≈ 0,44 USD giá niêm yết, trả bằng subscription) + 6 lần chạy CLI **không** gọi API (`tools-list` ×2 HOME rỗng, `lost-session`; chạy lại một lần sau khi gọn script). Ca `client-tools` lần 3 chạy khi `setup()` chưa tạo `sub/` (nên `Glob path=sub` báo "Directory does not exist") — không ảnh hưởng kết luận tên trường.

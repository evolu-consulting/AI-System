Sohoptac · Development Life Cycle

Bên trái: luồng từng step từ trên xuống. Bên phải: mỗi step cần những gì. Rê chuột vào một step để làm nổi bật cặp tương ứng.

App Dify Flow Cron job Agent Con người Sandbox / Automation Quay lại step trước - - Auto-approve (RAG check, bỏ qua con người)

Luồng tổng: User feedback (kèm url đang mở) → Dify tạo ticket Trello → Backend cron job theo dõi Trello → Spec Agent map spec với feature hệ thống, hỏi lại tới khi spec đủ, lập implement plan theo feature/domain → con người chốt spec → chia lane: Domain Agents lập implement plan (blast radius) + QC Agents viết testcases / test plan (lane chỉ để thiết kế plan) → con người approve, backend đưa plan của mọi lane vào 1 queue duy nhất của project → một lane, theo thứ tự queue, lặp tối đa 3 lần: implement → deploy dev trên sandbox → automation test (failed quay lại implement; quá 3 vòng thì dừng flow và escalate ngay cho con người) → Retro Agent gom findings & solutions → con người review, quyết định deploy prod và correct solution → Retro Agent nhận quyết định + solution, update ngược vào các agents.
Auto-approve: trước mỗi step của con người (5, 8, 13), agent ở step trước tra RAG xem case đang làm đã từng được con người approve chưa và có đơn giản không. Đơn giản và từng được approve → agent tự chạy tiếp step sau, không đợi con người (có ghi log để con người xem lại). Ngược lại → pause flow, đợi con người approve như cũ. Mọi quyết định của con người được ghi vào RAG làm căn cứ cho lần sau.

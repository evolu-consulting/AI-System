Knowledge Hub on a new Windows machine

Keycloak (sign-in) + KH server + the Prod kernel, from this folder, with no internet needed during the install. Built {{BUILT}}.

Is KH running? A KH icon in the taskbar tray (next to the clock) shows it for everyone who signs in on this machine: green dot = ready, amber = starting (loading the model, a few minutes after boot), red = stopped. Double-click opens KH Home; right-click has Swagger, Health, the log folder and, when stopped, Start KH. It is KnowledgeHub.exe --tray, registered at sign-in as KnowledgeHub Tray; it only watches, closing it never stops KH.

KH keeps its own data in local files beside the exe (C:\KH\kh: SQLite, Chroma, Kuzu). Java 21 and a small Python are bundled. Everything starts at boot.

What do I need first?

  • Windows 10/11 or Windows Server 2019+, 64-bit; an account with administrator rights.
  • 8 GB RAM, about 6 GB free disk.
  • Free ports 5433, 8180, 9000, 9180 (all can be changed, see options).
  • Python 3.10+ only on the machines where people use KH from Claude Code (for kh-helper), not for the install.

How do I install it?

  1. Copy the whole KH_Setup folder to the new machine.
  2. Open a Command Prompt as administrator in that folder and run (your own e-mail becomes the first maintainer): 
    .\install-kh.cmd --admin-email you@company.com --admin-first Your --admin-last Name
    It runs on the bundled Python, so a locked-down PowerShell (ConstrainedLanguage) does not matter.
  3. Wait 5-10 minutes. It ends with Knowledge Hub is installed. If a step fails, fix the cause and run the same command again: finished steps are skipped.

How do I sign in the first time?

  1. Your one-time password is in C:\KH\secrets\kh-accounts.json (accounts.admin.one_time_password); only administrators can open that folder.
  2. Open http://<host>:8180/admin/, sign in with your e-mail and that password, and set your own password. The same person exists in the master realm (Keycloak admin) and in knowledge-hub (KH maintainer); set the password in each on first sign-in.
  3. Connect Claude Code (on the server and on every machine that uses KH). Easiest: open Claude Code there and say 
    Read C:\KH\kh-helper\CLAUDE_CONNECT.md and connect this machine to KH at http://<host>:9000
    Claude runs kh-helper\setup-kh-helper.cmd: Python 3.12 if missing, kh-helper {{HELPER_VERSION}} offline into the Claude profile, kh login (you sign in in the browser), kh setup, then checks. On another machine, copy the kh-helper folder there first (from C:\KH or payload\). By hand, no administrator rights needed: 
    C:\KH\kh-helper\setup-kh-helper.cmd --kh-url http://<host>:9000
    Then restart Claude Code. The first prompt should show the KH kernel and a KH turn context.
  4. Add people from the Keycloak admin console (realm knowledge-hub, group kh-users) or with kh members add <project> <email> --level editable.

Google / Microsoft sign-in is off until you give their client ids: C:\KH\python\python.exe C:\KH\setup\deploy\btp\configure_realm.py --url http://localhost:8180 --client-id kh-local-admin --client-secret-file C:\KH\secrets\keycloak-admin-client.txt --idp-file <idp.json>
